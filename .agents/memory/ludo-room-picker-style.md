---
name: Ludo room picker style
description: Visual direction for the Mosquito App room-tier selection screen.
---

Use Clean Light Mode for the Ludo room picker: white/off-white page background, white cards with subtle #E2E8F0 borders and soft shadows, dark slate text, light status pills, and vivid green primary actions such as Join Room. Keep the room list responsive and retain Mosquito App branding.

**Why:** The user's newer app-wide Clean Light Mode request supersedes the earlier peach/gold room-list styling reference.

**How to apply:** Keep this direction presentation-only; room names, fees, available seats, confirmations, balance checks, stake reservations, and join behavior remain driven by the existing app and server.
